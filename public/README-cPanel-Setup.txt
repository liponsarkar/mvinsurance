========================================================================
   MV INSURANCE AGENCY - cPanel Deployment Instructions (সিপ্যানেল সেটআপ)
========================================================================

এই জিপ ফাইলটির ভেতরের সমস্ত ফাইল এবং ফোল্ডার আপনার cPanel হোস্টিং-এর
`public_html` ফোল্ডারের মধ্যে সরাসরি আপলোড এবং এক্সট্রাক্ট করার জন্য তৈরি করা হয়েছে।

------------------------------------------------------------------------
ক্লিক-বাই-ক্লিক নির্দেশাবলী (Step-by-Step Instructions):
------------------------------------------------------------------------

ধাপ ১: cPanel এ লগইন করুন
   - আপনার হোস্টিং প্রোভাইডারের cPanel ড্যাশবোর্ডে লগইন করুন (যেমন: yourdomain.com:2083)।

ধাপ ২: File Manager এ যান
   - cPanel এর "Files" সেকশন থেকে "File Manager" ওপেন করুন।

ধাপ ৩: public_html ফোল্ডারে প্রবেশ করুন
   - বাম পাশের ডিরেক্টরি ট্রি থেকে "public_html" ডিরেক্টরিতে ডাবল ক্লিক করুন।
   - (যদি আপনি সাব-ডোমেইনে চালাতে চান, তবে সেই সাব-ডোমেইনের নির্দিষ্ট ফোল্ডারে যাবেন)।

ধাপ ৪: জিপ ফাইল আপলোড করুন
   - উপরের মেনুবার থেকে "Upload" বাটনে ক্লিক করুন।
   - "mv-insurance-cpanel.zip" (অথবা cpanel-public_html.zip) সিলেক্ট করে আপলোড সম্পন্ন করুন।

ধাপ ৫: Extract (আনজিপ) করুন
   - File Manager এ ফিরে এসে আপলোড করা জিপ ফাইলের উপর রাইট-ক্লিক (Right Click) করুন।
   - "Extract" অপশনটি সিলেক্ট করুন এবং লোকেশন `/public_html` রেখে "Extract Files" চাপুন।
   - এক্সট্রাক্ট সম্পন্ন হলে জিপ ফাইলটি চাইলে ডিলিট করে দিতে পারেন।

ধাপ ৬: নিশ্চিত করুন .htaccess ফাইলটি আছে কিনা
   - এই প্যাকেজের সাথে একটি প্রি-কনফিগার করা `.htaccess` ফাইল দেওয়া আছে যা cPanel-এ 
     রিয়্যাক্ট সিঙ্গেল পেজ অ্যাপ্লিকেশন (SPA) রাউটিং এবং ফাস্ট ক্যাশিং হ্যান্ডেল করে।
   - যদি File Manager এ `.htaccess` না দেখেন, তবে File Manager এর উপরের ডানদিকের 
     "Settings" এ ক্লিক করে "Show Hidden Files (dotfiles)" চেক করে সেভ করুন।

ধাপ ৭: ওয়েবসাইট ব্রাউজ করুন!
   - আপনার ডোমেইন ভিজিট করুন (যেমন: https://yourdomain.com)।
   - হোমপেজের ব্যাকগ্রাউন্ডে গাড়ির ভিডিও, জানেত লোপেজ (Janet López)-এর ছবি,
     সবগুলো ক্যালকুলেটর, ফর্ম এবং পেজ অবিলম্বে কাজ করবে!

------------------------------------------------------------------------
প্রয়োজনীয় ফাইল তালিকা:
- index.html (মূল ফ্রন্টএন্ড কোড)
- .htaccess (cPanel Apache রাউটিং ও ক্যাশিং)
- assets/ (অপ্টিমাইজড জাভাস্ক্রিপ্ট ও সিএসএস বান্ডেল)
- images/ (জানেত লোপেজ এবং অন্যান্য ইন্স্যুরেন্স ছবি)
- videos/ (হিরো ব্যাকগ্রাউন্ড গাড়ির ভিডিও)
